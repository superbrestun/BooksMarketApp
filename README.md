# Books market app

Description:\
The program is a desktop bookstore management system written in C# using Windows Forms and the Entity Framework Core ORM, specifically for database management.

Techniques:\
The project was developed using Entity Framework Core and the Code-First approach. It uses an MSSQL database and Windows Forms. Composite keys have been configured for join tables, and cascading delete rules have been implemented. Data mapping attributes were also used, along with initialization with seed data in case the tables are empty.

Launch requirements:
- Windows 10 / Windows 11
- NET Runtime 8.0 or later
- MSSQL Server
